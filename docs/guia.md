# Guia do Projeto App de Trânsito

## Estrutura
- **mobile-app/** → código do aplicativo em React Native
- **web-site/** → código do site em HTML/CSS/JS
- **docs/** → documentação
- **README.md** → resumo do projeto

## Como rodar o app
1. Instale o Expo (`npm install -g expo-cli`)
2. Vá até a pasta `mobile-app`
3. Rode `npm install`
4. Inicie com `npm start`

## Como rodar o site
1. Vá até a pasta `web-site`
2. Abra o arquivo `index.html` no navegador
